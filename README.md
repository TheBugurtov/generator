# GenYOU Prompts Generator

🧠 **GenYOU** — это веб-приложение для генерации эстетичных и визуально насыщенных текстовых промптов. Идеально подходит для генерации описаний для аватаров, moodboard'ов, сцен для ИИ-изображений, сторителлинга и вдохновения.

## 🔮 Возможности

- Случайная генерация промптов из обширного набора (~200+)
- Кнопка для копирования текста в буфер обмена
- Кнопка для генерации нового текста
- Адаптивный и минималистичный UI
- Работает полностью офлайн (после загрузки)

## Как запустить

Просто открой файл `index.html` в браузере  
Или перейди по ссылке:  
[https://thebugurtov.github.io/generator/](https://thebugurtov.github.io/generator/)


## Используемые технологии

- HTML / CSS / JS (Vanilla)
- Font Awesome (для иконок)

## Структура

- `index.html` — основной файл, содержит весь код: разметку, стили, JS-логику
- Все данные (тексты) встроены прямо в JS (в массив `texts[]`)
