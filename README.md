# GenYOU Prompts Web App

Простой HTML/JS-проект, который отображает случайный текстовый промпт из большого массива и позволяет копировать его одним нажатием. Может использоваться как генератор описаний, визуальных сценариев, moodboard-идей и т.п.

## 🔧 Особенности

- Более 200 промптов в стиле lifestyle / creative / luxury / cozy / aesthetic
- Генерация случайного описания при загрузке страницы
- Возможность скопировать промпт в буфер обмена
- Кнопка перегенерации без перезагрузки страницы
- Сброс используется при исчерпании всех вариантов

## 💻 Как использовать

Просто откройте `index.html` в браузере. При каждой загрузке будет отображаться случайный текст. Можно кликать на иконку обновления для нового варианта и на иконку копирования — чтобы сохранить текст в буфер обмена.
